# Ranau 5Post for WooCommerce

Independent GPL-licensed WooCommerce pickup integration for 5Post. It synchronizes pickup points, filters them by the current parcel, calculates the configured customer rate, and stores a server-confirmed selection on the order. It does not create fulfilment orders.

Configure the 5Post and Yandex Maps credentials under **WooCommerce → Ranau 5Post**, synchronize the pickup-point directory, and add the shipping method to a zone.

Source and issues: https://github.com/yudin-s/ranau-5post-for-woocommerce

Optional paid support and custom development: https://ranau.uk/
